# What is this?
Tether is a game in Godot that I'm currently making. It's a sit and survive similarly to Five Nights at Freddy's but instead of being a security guard in a pizzeria, you are a scientist in the voids of space. You are supposed to observe if the loneliest parts of space really are that empty. Unfortunately for you, there is more activity then expected. 

### How to Play?
Press space to flash the space in front of you. Probably best to do so if you hear anything. Also you can't flash in front of you if you are looking at the front or have your computer down

A, S, and D to turn your camera or alternatively, hover your mouse of the sides of the screen to turn left and right.

Press W or hover your mouse over the top of the screen to pull down a computer. (as of now, it has little functoinality)

You can use A and D or click on the individual tabs to switch tabs

On the "Ship" tab specifically, you can use the number keys to switch the icon's position

# Creation Process
I dedicated several few hour chunks of time a week to work on the game where I begin hallucinating and trudging through as my brain turns into mush as I bang my head on my desk wondering how it's taking me so long to make a captcha button.

Being serious, the game is built in Godot which I've used for the few game jams I've participated in. All systems are created using Godot's GDScript and 3D functionality to create all of it's gameplay. Although almost everything visually are just placeholders, the spaceship was modelled in Blender. Throughout the project I've been trying to independently create everything without relying on tutorials. Despite that the computer screen and it's basic functionality specifically were created using the help of a tutorial.

This entire project does not contains work produced by AI.

# Opening from source
To open the project, download the files in this repo and put them all into a folder.

Install Godot either from https://godotengine.org/ or through steam

Open Godot and while on the project list, press the "Import" button and select the folder with the game files.

Godot should recognize the folder to be a valid Godot project and allow you to run the project and edit it however you may please.

Alternatively, if you would like to just try the project, I have an itch.io page where you can play exported tests of the game. The link is the link to it.
