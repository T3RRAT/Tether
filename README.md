This is the project files for a game I'm making. The basic premise is that you are a scientist who is sent to the void of space to gather information but you aren't alone. 
The game mostly is baren at the moment but occasionally a monster spawns and you will need to flash it to make them go away
To run this, download the files and put them all into a folder. 
Open Godot and on the project list press Import and select the folder with the files.
